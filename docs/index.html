What is Subvocal SDK?

Open-source, hardware-agnostic middleware. sEMG capture → conditioning → classification → articulatory shorthand → context-aware intent → action. Swap drivers, classifiers, and LLM providers without changing pipeline code.

Read docs →
Articulatory Shorthand
Bypasses 5–8 word vocabulary ceiling. Compressed consonant strings decoded via asymmetric Levenshtein with physiological confusion clusters (Labial, Alveolar, Velar, Rhotic).
Context Prioritization
Dynamic filtering against active contacts (TYPE), calendar (SEARCH), browser URLs (GOTO), and on-screen elements (CLICK) — then LLM rescoring when needed.
Signal
Physiological conditioning
1.3–50 Hz bandpass for slow articulatory gestures + correctly plumbed 50/60 Hz notch. TD10 features, 840-d per segment.
Runtime
Hardened v2 pipeline
Bounded OpsQueue with backpressure, thread-safe inject_token, 5s deadlock-free step, JSONL tracing with 10 MB rotation (opt-out).
Protocol
MCP stdio server
Expose intent decoders as Model Context Protocol tools. Works with Claude Desktop: subvocal-mcp

Built for privacy first

Fully offline. Raw biopotentials, feature vectors, and shorthand logs stay on local CPU threads — never sent to external cloud. Pipeline JSONL tracing is opt-out via telemetry.trace_enabled / runtime.trace_enabled and capped at 10 MB.

FAQ

How does it avoid vocabulary ceilings?+
Whole-word sEMG classifiers degrade beyond ~8 words. Subvocal uses compressed phonetic shorthand (consonant strings like g gl for Google) decoded via asymmetric Levenshtein over anatomical confusion clusters, then context + LLM rescoring.
Do I need custom neckbands or sensors?+
No. Supports OpenBCI Cyton, Delsys Trigno, FileReplay, and Synthetic generators. BrainFlow-compatible BoardShim fallback is pure-Python with bounded buffers — no native deps.
Which LLM providers are supported?+
Claude, OpenAI, Gemini, and local Llama via Ollama. resolve_provider() picks the best available (env API key → heuristic offline). Per-request timeouts + exponential backoff on 408/429/5xx.
What is the MCP server?+
A stdio Model Context Protocol server exposing get_pipeline_status, get_token_buffer, inject_token (thread-safe), process_phrase, trigger_calibration, and resource subvocal://intent/history.
What changed in 2.0.1?+
Security & reliability hardening: restricted unpickling, path-traversal guards, HMAC padding fix, TTS injection sanitization, bounded queues, deadlock-free pipeline (5s HardwareError), validated Frame/CommandToken, low-cardinality Prometheus (no session_id).
Is it open source?+
MIT licensed. GitHub → includes v2.0.1 hardening + research frontier modules under subvocal[ml] (handcrafted 112, SPD, adaptor, MONA/LISA, SpeechNet, etc.).
