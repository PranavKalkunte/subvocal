Failure profile — why hybrid?

13 heuristic failures highlight where LLM reasoning wins.

Pluralization
srch nrl ntwk
Expected SEARCH neural networks → got Neural network (singular bias — shorter Levenshtein distance).
Fix: LLM picks plural via language semantics.
Phonetic tie
srch fgt calb
Expected Figma calibration → got logout confirm (fgt→logout tie, hallucinated bigram).
Fix: LLM knows “Figma calibration” is a calendar event.
Vocab collision
srch snt spch
Expected silent speech → got send Speech (snt→send present in dictionary).
Fix: bigram cohesion “silent speech” vs “send speech”.

How to run

One harness, every bench imports subvocal. Heuristic runs offline; hybrid needs API keys.

Start building → GitHub
terminal
# heuristic — no keys, deterministic
PYTHONPATH=src python3 benchmarks/eval_runner.py

# live LLM — picks best provider with key present
export ANTHROPIC_API_KEY=... # or OPENAI_API_KEY / GEMINI_API_KEY
PYTHONPATH=src python3 benchmarks/eval_runner.py

# install extras
pip install "subvocal[all,dev]"  # then pytest / ruff / pyright
